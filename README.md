# 🧬 Generative AI for Modeling Living Tissues and Collective Cell Dynamics

### Генеративный ИИ для моделирования живых тканей и коллективной динамики клеток

Годовой проект по исследованию методов машинного обучения для анализа и моделирования коллективной динамики клеток по данным микроскопии.

---

## 📌 О проекте

Морфогенез, заживление ран и опухолевая инвазия — процессы, в которых клетки движутся коллективно, подчиняясь биологическим и физическим закономерностям.

В рамках проекта планируется исследовать возможности применения современных методов машинного обучения для анализа микроскопических данных и построения моделей, способных описывать и прогнозировать динамику клеточных систем.

Проект предполагает работу с данными микроскопии, анализ движения клеток, исследование подходов к моделированию их коллективной динамики и оценку качества получаемых предсказаний с учётом физических свойств системы.

---

## 🎯 Цель проекта

Разработать и исследовать подходы к анализу и прогнозированию коллективной динамики клеток на основе данных микроскопии с использованием современных методов машинного обучения.
